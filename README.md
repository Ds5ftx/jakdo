# 기하 작도판

웹 브라우저에서 바로 쓰는 **동적 기하 작도 앱**입니다. 점·선·원을 작도하면 부모–자식 관계가 기록되어, 자유점을 끌어도 평행·수직·교점·측정값 같은 관계가 그대로 유지됩니다. 설치 없이 `index.html` 하나로 동작합니다.

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| 도구상자 | 화살표(이동·회전·확대), 점, 컴퍼스, 직선자(선분·반직선·직선), 다각형, 텍스트, 표시(각·눈금·손그림), 정보, 사용자 도구 |
| 파일 | 여러 페이지(시트 탭), 열기(.json · GSP 4/5 .gsp · JavaSketchpad .htm)·저장(.json · GSP 5 .gsp), 그림 가져오기, PNG·웹 페이지로 내보내기, 문서 보관함, 예제 |
| 편집 | 실행 취소/다시 실행, 복사·붙여넣기, 동작 버튼(숨기기/보이기·애니메이션·이동·발표·소리·링크·스크롤), 분리/병합, 정의 편집, 속성, 환경설정 |
| 표시 | 점·선 스타일, 색(매개변수 색 포함), 텍스트 팔레트, 자취, 애니메이션, 운동 조절기 |
| 작도 | 대상 위의 점, 중점, 교점, 평행선, 수선, 각의 이등분선, 원·호, 내부, 자취 |
| 변환 | 평행이동, 회전, 확대·축소, 대칭이동, 반복(프랙털), 사용자 정의 변환 |
| 측정 | 길이, 거리, 각, 넓이, 둘레, 호, 비, 좌표(극좌표 포함), 기울기, 방정식 |
| 수 | 매개변수, 계산기, 표, 함수, 도함수(기호 미분) |
| 그래프 | 좌표계(정사각·직사각·극 격자), 점 그리기, 함수 그래프(y=, x=, r=), 매개곡선 |

## 바로 써 보기

`index.html`을 내려받아 브라우저에서 열면 됩니다. 작업 내용은 그 브라우저에 자동 저장됩니다.

## GitHub Pages로 공개하기

1. 이 저장소를 GitHub에 올립니다.
2. 저장소의 **Settings → Pages**에서 *Source*를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

## 폴더 구조

```
index.html     배포용 단일 파일 (build.py가 만듦)
build.py       src/를 묶어 index.html을 만드는 스크립트
src/
  shell.html   화면 골격과 스타일
  core.js      문서 모델, 의존 그래프, 기하 계산, 수식 파서, 측정
  render.js    캔버스 그리기, 선택 판정
  graph.js     좌표계, 함수 그래프, 기호 미분, 수치 교점
  ui.js        도구, 포인터 입력, 작도·측정 명령, 애니메이션, 파일
  menus.js     대화상자, 메뉴, 도구상자
  iter.js      표, 반복, 사용자 정의 변환
  tools.js     사용자 도구, 분리/병합, 손그림, 그림
  display.js   매개변수 색, 수식 표기·핫 텍스트, 텍스트 팔레트, 버튼, 내보내기
  extras.js    세부 기능(방향각, Shift 고정, 레이블 붙이기, 인쇄, 끌어다 놓기 등)
  gspimport.js GSP 4/5 문서(.gsp)·JavaSketchpad(HTML) 불러오기
  gspexport.js GSP 5 문서(.gsp)로 저장
  complete.js  글자 스타일·도구·고급 환경설정, SVG 내보내기, 계산 단위, 표본 변환 그림 등
  pages.js     여러 페이지(시트 탭)와 저장 형식
  examples.js  예제와 시작 코드
```

## 수정하고 다시 만들기

`src/`의 파일을 고친 뒤 다음을 실행하면 `index.html`이 새로 만들어집니다. (Python 3 필요, 외부 패키지 없음)

```bash
python3 build.py
```

## 참고

- 글꼴은 Google Fonts(IBM Plex Sans KR, STIX Two Text, IBM Plex Mono)에서 불러오며, 오프라인에서는 시스템 글꼴로 대체됩니다.
- 저장 파일(.json)은 모든 페이지를 담으며, 이 앱의 **파일 ▸ 열기**로 다시 불러옵니다.
- **파일 ▸ 열기**나 끌어다 놓기로 GSP 4/5 문서(.gsp)와 JavaSketchpad로 내보낸 HTML도 열 수 있습니다. 페이지·사용자 도구·측정값·함수·변환·버튼·그림·반복을 가져오며, 아직 해석하지 못하는 일부 객체는 건너뜁니다.
- **파일 ▸ GSP 5 문서로 저장**으로 모든 페이지를 GSP 5에서 열 수 있는 .gsp 파일로 저장합니다. 점·선·원·호·교점·변환·측정(좌표·방정식 포함)·계산·함수와 그래프·매개변수·자취·글상자·그림·반복(반복 표 포함)·표·숨기기/링크/웹 주소/애니메이션/이동/화면 이동/동시·연결 실행 버튼과 사용자 도구를 옮깁니다. 소리 버튼은 GSP의 소리 버튼(함수 그래프를 소리로 재생)과 하는 일이 달라 저장하지 않습니다.
